# 00 — Project Brief

**Purpose:** One-page source of truth for what is being built and why. **Status:** Proposed · **Last reviewed:** 2026-10-18

## 1. Summary
| Item | Value |
|---|---|
| Working title | OPERATION: EMBERWATCH (`Needs Validation` — name/trademark check, REL-010) |
| Platform | Android phones (tablets supported, not optimised in MVP) |
| Genre | Story-driven military action-progression, 2.5D, single-player |
| Orientation | Landscape (locked) |
| Session length | 8–15 min per mission; 20–40 min typical sitting |
| Campaign length (MVP) | ~5–7 hours (estimate) |
| Connectivity | Fully offline |
| Business model (MVP) | Premium-feel, free of forced ads; monetization deferred (see [18](18_MONETIZATION_AND_FAIR_PLAY.md)) |
| Team assumption | 4–8 people (1–2 engineers, 1 designer/writer, 1–2 artists, 1 audio/part-time, 1 QA/part-time). `Needs Validation` with founder |

## 2. Audience (Proposed)
| Attribute | Decision |
|---|---|
| Age suitability | Teen (13+ equivalent); stylised conflict, no gore, no real-world factions. Final rating comes only from the IARC questionnaire (REL-020) |
| Skill level | Casual-to-mid-core; three difficulty modes (Cadet/Standard/Veteran) |
| Device segment | 2020+ mid-range Android, 4 GB RAM, plus low-tier profile for 3 GB devices |
| Accessibility | Subtitles on by default, colour-blind-safe markers, one-hand-friendly layout option, haptics toggle, aim assist scale |
| Disclaimer | Entertainment only. Not a training tool. Fictional nations. |

## 3. Pillars (summary; authoritative in [01](01_GAME_VISION_AND_DESIGN_PILLARS.md))
Earned Rank · Varied Rhythm · People over Plot · Choices that Echo (but are affordable) · Readable on a Phone.

## 4. MVP definition
Prologue P-01 plus missions M-101…M-105, M-201…M-203, M-301, M-401, M-402 (12 playable entries). Three endings. Local saves. Original art/audio. See [05](05_CAMPAIGN_AND_MISSION_DESIGN.md).

## 5. Out of scope (MVP)
Multiplayer, accounts, cloud saves, open world, online leaderboards, IAP, ads, iOS, voice acting beyond key lines, procedural campaign.
