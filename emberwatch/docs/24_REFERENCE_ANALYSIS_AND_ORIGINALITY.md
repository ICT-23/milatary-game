# 24 — Reference Analysis and Originality

**Purpose:** Record what was learned from the genre reference and how EMBERWATCH differs. **Status:** Proposed · **Last reviewed:** 2026-10-18

## 1. Reference and method
Reference: *Military Academy 3D* (Google Play id `com.slg.MilitaryAcademy3D`). **The store page was not opened or analysed in detail during this documentation pass;** the brief authorises use at the level of genre and general design principles only. This file therefore lists the *brief's* high-level ideas, and any deeper comparison must be added by someone who has played the game, still without copying specifics.

## 2. High-level lessons taken (genre-level only)
| Lesson | Our adaptation |
|---|---|
| Recruit-to-officer fantasy | Six-rank ladder with Lantern naming, earned through story missions |
| Academy training as onboarding | Training is a narrative chapter (Ch.1) with consequences |
| Short activities in a larger loop | 6–18 min missions feeding XP, trust and unlocks |
| Mobile-friendly controls | Landscape stick + action cluster, aim assist, left-handed mirror |
| Unlockable gear & milestones | Earn-only RC/MP economy, no pay-to-win |

## 3. Difference table
| Dimension | EMBERWATCH |
|---|---|
| Story | Flood-relief conspiracy about a failed beacon network; antagonist has understandable motives |
| World | Fictional Republic of Corvane, Harlow Reach, Sable Compact |

## 4. Originality rules (enforced)
| ID | Rule |
|---|---|
| ORG-001 | No assets, text, names, UI layouts, audio or code from the reference or any third-party game |
| ORG-002 | No scraping/downloading store screenshots into the repo; no overlay tracing |
| ORG-003 | Reference Log (source, licence, use) is mandatory for all inspiration images |
| ORG-004 | Reviewer checks every key art/UI screen against ORG-001 before approval |
| ORG-005 | Store metadata must not use the reference's name or imply affiliation |
| ORG-006 | If in doubt, change it |
